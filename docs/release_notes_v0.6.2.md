## 自动更新

- 启动 12 秒后静默检查 GitHub Releases（可在 设置 → 关于 关闭），发现新版本
  即后台下载并校验；下载完成后托盘气泡或「关于」页给出「立即更新」，点击后
  程序退出、更新脚本替换文件并自动重启
- 装的是 full 包就升 full，标准包升标准包；仍可手动下载 zip 覆盖

## 翻译

- 在线直连新增**必应**（Edge 内置翻译接口）作为默认第一通道：
  必应 → Google GTX → MyMemory 三通道容灾，三路都没有的块再转离线插件
- 必应免 Key、自动识别源语言，支持 简中 / 繁中 / 英 / 日 / 韩 目标语言
- 必应为微软非公开端点，地址变动时自动落到后级通道

## 截图与长截图

- **线条粗细**：色板右侧 1-10 滑块（值即像素宽），拖动时刚画的形状实时变粗，
  松手 0.4s 后写入配置
- **双快捷键**：每个功能可绑定两个组合（设置 → 快捷键 左右两个输入框）
- **复制不再变糊**：复制图片改写 Win32 剪贴板，只提供无损格式
  （CF_DIBV5 / CF_DIB / PNG / CF_BITMAP），粘贴到微信、QQ、文档不再被
  有损编码压糊，圆角透明保留
- **长截图**：
  - 自动滚动改由真实滚轮输入驱动，指针只移动一次到选区中心，移出选区即暂停、
    移回继续
  - 进入长截图后选区冻结，避免「框一变、拼接就乱」
  - 预览窗用 `WDA_EXCLUDEFROMCAPTURE` 从抓屏中剔除，压在选区上也不会被拼进长图
  - 工具栏提示气泡不再被抓帧拼成水印
  - 新增「贴图并翻译」
- 贴图右键「翻译（替换原图）」期间底部显示「翻译中...」，译完直接替换原图
